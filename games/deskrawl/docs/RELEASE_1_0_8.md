# Deskrawl 1.0.8 正式发布

修复游戏 `1.1.11a / Steam Build 26606215` 更新后，人物、材料和背包入口无法验证的问题，适配新版本三套天赋配置。本地 `1.0.7` 已登记交付，正式包使用 `1.0.8` 从干净源码提交重建；不覆盖本地包或历史公开资产。

## 变化

- 保留原有 37 项语义契约及历史变体，新增 11 个完整方法体变体和 18 个依赖证明；验证调用关系、字段类型、保存路径及唯一目标。
- 可用天赋点使用新余额与原生通知路径，保留三套已分配天赋和当前选择；旧构建继续使用经验证的原增量方法。
- 经验写入验证新增天赋点补齐调用链；物品名称验证特殊名称、模板、本地化及递归调用。
- IL2CPP 同类元数据别名共用同一完整验证目标时合并，不同目标及不同类继续拒绝歧义。缓存包含完整依赖图。
- 金币在游戏主线程写入后立即核对，随后自然收益不会再触发已成功修改的误报。

Host API 8，最低主程序 `0.5.1`；六个编辑器稳定 ID、旧构建契约及独立功能降级保持不变。此次仅发布 Deskrawl 模块，主程序仍为 `0.5.5`。未知构建仍需本地只读结构验证，诊断不安装业务钩子、不刷新或保存。

## 验证与边界

2026-11-14 的实机结构与恢复证据见 [SMALL_UPDATE_1_1_11A.md](SMALL_UPDATE_1_1_11A.md)：8 项能力检查、变化/缺失指纹、过期进程拒绝、故障隔离，以及 13 项人物字段、31 种中文材料、14 种已有可堆叠物品和规则读取通过。天赋点测试差额已恢复，三套分配字典及当前选择不变；成功轮次的金币、物品测试差额已移除，规则及最终属性入口恢复。

用户手动重启后，余额、基础主属性、巅峰点、当前配置及三个配置的条目数量与重启前一致。测试增量在重启前已恢复，该复核不是保留新增点数跨重启的独立持久化证明，也不代替逐项天赋内容、战斗收益或视觉验收。

正式发布重新执行模块构建、Schema、小更新契约、语义夹具、249 项页面回归及当前宿主实际 ZIP 加载。DLL ProductVersion 追踪同一源码提交与带注释发布标签；公开资产 SHA-256 核验通过后，目录单独提交并保留历史完整版本快照。既有完整离线包仅供本地分发，不上传为 GitHub Release 资产。
