## 经审查的差异

以下六项在只替换表中具体成员位移后，整段规范化指令的 SHA-256 与既有契约精确相同。字段类型及用途同时由当前元数据和调用路径核对；不是在生产解析中通配位移。

| 历史角色键 | 旧访问 → 当前访问 | 当前语义 |
| --- | --- | --- |
| `FishingMapData|ccq` | `ItemData + 0x34 → 0x38` | `ItemEffect`，钓鱼候选特殊倍率分支 |
| `hh|dyp` | `GameConfig + 0x124 → 0x11C` | `ParagonPointsPerLevel`，巅峰总点数 |
| `Inventory|fcb` | `ItemData + 0x88 → 0x98` | `MaxStackSize`，分堆入库 |
| `Inventory|fcp` | `ItemData + 0x8C → 0x9C` | `MaxCarry`，携带上限 |
| `Player|bjy` | `Player + 0x350 → 0x360` | 属性转换列表，最终属性消费者 |
| `SaveSystem|egw` | 布尔状态 `+ 0xC1 → 0xC2` | 保存入口的延后保存保护；仍收集 SaveData/SavedStash 并进入原保存链 |

`Player|fko` 的经验需求计算则真正重写。新增完整函数变体，并独立验证游戏的经验数量、基础经验和插值计算三段函数，以及外层到两个计算函数、数量计算到插值函数的真实调用/尾调用目标。相同调用者摘要不足以批准换了目标的调用。

旧 `Hash`、`LegacyHash` 和指令数全部保留。新变体分别携带自己的完整指令数和摘要，适应重写后的不同函数长度；不读取固定 RVA，不按混淆名或同签名直接调用。更新 `go`/`hw` 只作为已观察类型提示，仍须完整语义验证，提示失效时保留有上限的候选搜索。

当前构建刻意继续走未登记指纹路径，验证不是通过补哈希放行。既有角色、六页 ID、Host API 8、最低宿主 0.5.1 不变。

## 验证

- 模块及五模块实机测试项目 Release 构建通过，0 警告、0 错误。
- 模块 Schema、视觉所有权、小更新强制契约通过。
- 指令夹具覆盖重定位、常量、局部跳转、字段位移、唯一/缺失/歧义，以及调用目标被替换、缺失和尾调用。
- 当前游戏的八项兼容检查全部通过；变化/缺失指纹仍执行实际验证；过期实例拒绝。
- 向测试进程注入人物契约失配时，人物直接入口拒绝，核心、材料、钓鱼保持可用；未改变游戏结构。
- 六页快照通过：13 项人物字段、31 种中文材料、14 项已有可堆叠物品、三类规则页。
- 独立存档备份后，金币小幅往返、材料/可堆叠物品减少 1 再增加 1，经游戏主线程、业务入口、保存调用和实时回读完成；恢复只撤回测试增量，保留自然收益。
- 装备最高词条、钓鱼成功率、装备掉落率、特殊掉落倍率实际设置并恢复。测试首次在恢复特殊倍率时将操作哨兵 `-1` 误作有效倍率回读值，属于测试断言错误；游戏已完成恢复。随后只读确认全部规则回归原状态，没有重发不确定业务操作。
- 八项最终属性写入通过最终消费者回读；测试后验证跳转归属并恢复精确原始函数入口，未留下同值覆盖冻结自然属性。
- 用户手动退出并重新启动游戏后，新进程再次通过八项结构验证、指纹变化/缺失与故障隔离回归，以及六页只读快照；重新识别 13 项人物字段、31 种中文材料和 14 项已有可堆叠物品。没有为这一步再次改变游戏数值。

上述为当前进程的结构、读写、消费者回读和恢复证据，不等于全部战斗/掉落效果及新版本重启持久化已经验收。经验、天赋、巅峰、基础主属性的持久写入实现未改写，本轮没有逐项改变这些角色进度。不得把旧版本持久化证据冒充本轮结果。
