# Deskrawl 1.0.6 正式发布

本版修复游戏 `1.1.0a / Steam Build 26337088` 更新后，人物、钓鱼、材料、可堆叠背包和保存结构检查拒绝的问题。本地 `1.0.5` 已交付并登记，正式包从干净源码提交重新构建，使用下一版 `1.0.6`，不复用旧包版本或覆盖历史资产。

## 内容

- 保留原有 34 项语义契约，新增七个经审查的完整函数变体，不靠补充构建哈希放行。
- 经验计算重写后，分别验证三个辅助函数及其真实调用或尾调用关系；调用者摘要相同但目标被替换时拒绝。
- 人物、装备、掉落、钓鱼、材料、背包及保存继续按所需结构独立验证与降级，诊断不执行业务修改或保存。

Host API 8，最低宿主 `0.5.1`；六个编辑器的稳定 ID 不变。本次只发布 Deskrawl 模块，主程序仍为 `0.5.5`。

## 验证与边界

当前游戏的完整结构验证、变化/缺失指纹、过期实例、故障隔离、六页读取、可恢复写入以及用户手动重启后的读取证据见 [SMALL_UPDATE_1_1_0A.md](SMALL_UPDATE_1_1_0A.md)。金币、材料和可堆叠物品的测试增量已撤回，规则与最终属性入口已恢复；保留游戏自然收益。全部测试增量在重启前已恢复，重启验证不构成保留测试数值跨重启的持久化证明，也未重新逐项验收战斗/掉落效果或全部角色进度写入。

发布检查覆盖全模块 Release 构建、小更新强制契约、语义夹具、页面协调，以及宿主加载真实正式 ZIP。最终 DLL 的 ProductVersion 必须指向带注释发布标签的同一源码提交。公开资产核验成功后才更新模块目录，并保留历史不可变快照；完整离线包不上传 GitHub。
